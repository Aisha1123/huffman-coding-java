Overview:
This project implements Huffman encoding and decoding in Java. Huffman coding uses character frequencies to assign binary codes and encode messages.

Features:

- Builds a Huffman tree based on character frequencies.
- Uses a priority queue to combine nodes and construct the tree.
- Generates binary codes for characters.
- Encodes messages and decodes binary text back into the original message.
- Uses file input/output to store encoded messages and coding schemes.

Concepts Used:
- Java
- Data structures and algorithms
- Binary trees
- Priority queues
- HashMaps
- Recursion
- File input/output

Purpose:
This project helped me practice implementing tree-based algorithms and working with data structures in Java.
